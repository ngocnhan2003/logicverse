# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/c28fe457-d545-4b48-a4c6-94ec0170f59f

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

> No API keys are required. All puzzles are generated by a fully local
> procedural engine, so the games run completely offline / self-contained.
